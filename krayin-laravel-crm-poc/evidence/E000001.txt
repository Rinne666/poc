1: # Security Policy
2:
3: ## Supported Versions
4:
5: Krayin CRM follows Laravel's release cadence. The 2.2 line, built on
6: Laravel 12, receives bug and security fixes. The 2.1 line receives
7: security fixes only. Earlier lines are End of Life, and users should
8: upgrade to the latest 2.2 release.
9:
10: | Version | PHP required | PHP tested | Laravel | Release            | Bug Fixes | Security Fixes |
11: | ------- | ------------ | ---------- | ------- | ------------------ | --------- | -------------- |
12: | 2.2     | 8.3+         | 8.3        | 12.x    | March 17th, 2026   | Yes       | Yes            |
13: | 2.1     | 8.2+         | 8.2, 8.3   | 10.x    | March 26th, 2025   | No        | Yes            |
14:
15: **Current:** 2.2.x
16:
17: ## End of Life
18:

20: version.

29: ## Reporting a Vulnerability
30:
31: Report security issues privately. Do **not** open a public GitHub
32: issue, pull request or discussion.
33:
34: **Email** — [support@webkul.com](mailto:support@webkul.com)
35:
36: Please include:
37:
38: - A description of the issue
39: - Steps to reproduce (and a PoC, if available)
40: - Impact assessment (CVSS 4.0 or 3.1 vector welcome)
41: - Affected version(s)
42: - A suggested fix, if any
43:
44: ## Security Process
45:
46: For every **supported** line (any row in the Supported Versions table
47: with Security Fixes marked Yes), the flow is:
48:
49: 1. **Acknowledgement** within 72 hours
50: 2. **Triage** — reproduction and severity assessment
51: 3. **Fix development** on `2.2`, the current release line, then
52:    backported to every other supported line
53: 4. **Patched releases** for each supported line, with the fix listed
54:    under a `[security]` entry in the [changelog](CHANGELOG.md)
55: 5. **GitHub Security Advisory** published with the reporter credited
56:    (when the reporter consents)
57:
58: We aim to ship patches within **14 days** of acknowledgement for high
59: or critical severity, and **30 days** for medium severity.
60:
61: Please give us a reasonable chance to release a fix before you
62: disclose the issue publicly.
